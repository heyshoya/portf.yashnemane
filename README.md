# Yash Nemane - Portfolio

A React and Vite portfolio site.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production site is generated in `dist/`. Relative asset paths allow the build to work both at the root of a domain and under a GitHub Pages project URL.

## Deploy

Push to `main` to build and publish the site with GitHub Pages. In the repository settings, set **Pages > Build and deployment > Source** to **GitHub Actions**.
